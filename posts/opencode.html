¿Qué es OpenCode?

  • Licencia MIT: Es un agente de programación de código abierto diseñado para operar principalmente en la terminal (CLI/TUI), contando también con apps de escritorio y extensiones para diversos IDEs.
  • Popularidad en GitHub: Cuenta con más de 176.000 estrellas en GitHub, consolidándose como una de las herramientas más completas para el desarrollo asistido por IA.

¿Cómo funciona OpenCode?

A diferencia de un simple chatbot, OpenCode opera mediante un bucle agéntico de forma autónoma hasta completar una tarea. Su flujo se divide en dos estados principales que alternás con la tecla Tab, sumando además subagentes:

  • Modo Plan: Es un entorno de solo lectura ideal para explorar bases de código desconocidas o diseñar estrategias sin riesgo de modificar tus archivos.
  • Modo Construir: Es el modo de acción predeterminado, donde el agente tiene permisos de escritura para editar archivos y ejecutar comandos reales en el sistema.
  • Subagente @general: Una herramienta interna diseñada específicamente para realizar búsquedas complejas y ejecutar tareas de múltiples pasos de forma eficiente.

Características técnicas clave

OpenCode entiende el contexto de tu proyecto mediante el comando /init, generando un archivo AGENTS.md con la estructura del código. Integra las siguientes tecnologías:

  • LSP (Language Server Protocol): Sirve para recibir diagnósticos y errores de compilación en tiempo real directamente del lenguaje de programación que estés usando.
  • MCP (Model Context Protocol): Actúa como un juego de adaptadores universales para conectar la IA con herramientas externas como bases de datos, navegadores web o servicios en la nube.
  • Skills y Plugins: Son conocimientos empaquetados y extensiones que modifican el comportamiento del agente según tus necesidades de desarrollo.
  • Auto Compact: Funciona como un resumen inteligente de una larga charla; cuando la memoria de tokens llega al 95%, compacta todo automáticamente para seguir la sesión sin perder el hilo.

Diferencias con otros modelos y opciones de acceso

A diferencia de herramientas atadas a un solo ecosistema, OpenCode es agnóstico y soporta más de 75 proveedores de modelos. El entorno te ofrece las siguientes ventajas:

  • Modelos soportados: Podés elegir entre opciones premium como GPT-4 o Claude 3.5 Sonnet, o ejecutar modelos locales fuera de línea mediante Ollama o LM Studio.
  • OpenCode Zen: Una selección curada de modelos recomendados y verificados minuciosamente por el equipo para garantizarte el mejor rendimiento.
  • OpenCode Go: Una suscripción mensual de bajo costo (5 dólares el primer mes, luego 10 dólares mensuales) para acceder a modelos abiertos de programación de forma estable.
  • Soberanía de datos: Bajo una filosofía local-first, el código permanece en tu máquina y te permite aprovechar suscripciones existentes de Copilot o ChatGPT Plus, cuidando tus costos.

Instalación y requisitos

Para empezar a usarlo, requerís una terminal moderna. La instalación se realiza directamente desde la consola:

  • Terminales soportadas: El entorno exige emuladores modernos como WezTerm, Alacritty, Ghostty o Kitty para renderizar correctamente la interfaz interactiva.
  • Script de instalación: Podés activar la herramienta ejecutando de forma directa en tu terminal el comando: curl -fsSL https://opencode.ai/install | bash.

Comandos interactivos de la TUI e integración con GitHub

La herramienta te permite controlar todo el flujo de desarrollo mediante comandos específicos dentro de la terminal, expandiendo su poder directamente a tus repositorios remotos:

  • Comandos esenciales: Tenés a mano opciones clave como /undo para deshacer, /redo para rehacer, /share para compartir, /connect para enlazar servicios y /models para cambiar de modelo.
  • Integración nativa: Funciona perfectamente con la GitHub App y flujos de automatización en GitHub Actions.
  • Invocación autónoma: Podés llamar al agente en tus issues o pull requests usando los comandos /opencode o /oc para que solucione problemas por su cuenta.

Resumen: OpenCode se actualizó a más de 176.000 estrellas e integra el subagente @general, la función Auto Compact, los servicios Zen y Go, comandos de TUI avanzados e integración nativa con GitHub Actions.
